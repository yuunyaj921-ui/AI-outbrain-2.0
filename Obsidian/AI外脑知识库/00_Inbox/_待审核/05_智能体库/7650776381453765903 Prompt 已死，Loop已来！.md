# 从 Prompt 到 Loop：让 Agent 围绕验收标准自主迭代

## 📌 一句话总结
相比人工逐轮修改 Prompt，Agent Loop 的核心是预先定义目标和验收标准，让智能体执行、测试、复盘、记录并继续迭代，直到达到标准或触发人工接管。

## 🏷️ 类型
智能体

## 🔑 关键知识点
1. **Prompt 工作方式**：人查看每轮结果、指出问题并再次发起；人仍是循环的调度者。
2. **Loop 工作方式**：人提供目标、截止条件与验收标准，Agent 自行执行、检测、修复和复查。
3. **可追踪记忆是关键**：每轮要记录做了什么、失败原因、判断依据和下一步；否则只是重复运行，并不会稳定改进。
4. **验收应独立于“自称完成”**：用测试、检查清单、独立评审或人工终审判断是否合格，减少幻觉式完成。
5. **必须设置停止与升级条件**：轮次、时间、成本、权限或连续失败达到阈值时停止，并交给人处理。

## 🎯 适用场景
- 有明确可测试结果的软件开发与修复任务
- 可用检查清单验收的内容生产和资料加工
- 需要保留失败证据、决策记录和审计轨迹的自动化流程
